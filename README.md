# coffee-house-landing-page
☕ Coffee House — Responsive Coffee Shop Landing Page  

A fully responsive Coffee House landing page built from scratch using HTML, CSS, and JavaScript. This project includes a modern hero section, about section, menu cards, image gallery, customer reviews, responsive contact form, mobile navigation, animations, and a responsive footer. Built as my first complete front-end project while learning and practicing web development.
