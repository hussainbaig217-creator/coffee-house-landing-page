# ☕ Coffee House — Responsive Coffee Shop Landing Page

A modern, responsive coffee shop landing page built from scratch
using HTML, CSS, and JavaScript.

## 🚀 Live Demo

Coming soon — deployed with Vercel.

## ✨ Features

- Responsive navigation
- Hero section
- About section
- Coffee menu cards
- Responsive image gallery
- Customer reviews
- Responsive contact section
- Contact form UI
- Hover animations
- Mobile responsive design
- Smooth scrolling
- Responsive footer

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Responsive Design
- Vercel
